# 📘 SmartStudy Bot – AI Internship Project

## 📌 Overview
SmartStudy Bot is a command-line AI assistant built using Large Language Models (LLMs). It helps students learn efficiently by providing:

- Interactive AI Chat
- Automatic Quiz Generation
- Smart Notes Summarization

---

## ⚙️ Features

### 1. Chat Mode
Ask any academic question and get AI explanations in simple language.

### 2. Quiz Generator
Generates multiple-choice questions (MCQs) from any topic.

### 3. Summarizer
Converts long study notes into short bullet points.

---

## 🧠 Technologies Used

- Python
- Google Gemini API
- Prompt Engineering
- CLI Application Design
